# Privacidad / Privacy

## English

Lodestar does not collect analytics, telemetry, account data or game ownership data, and it does not send information to the project authors.

**Local network panel.** The web panel runs on your console (port 8770) and is reachable from your local network. It has no password: stop Lodestar when finished if you share the network with other people.

**Downloads you choose.** If you paste a download link or use the browser extension, the console contacts that server directly to download the file. The remote server can see the console's IP address like any HTTP download. Lodestar does not proxy the transfer through another service.

**No cloud storage integration.** Lodestar no longer includes Google Drive, NAS, SMB, NFS or FUSE support. It does not ask for Google credentials and does not store cloud tokens.

**Local files.** Settings, logs, transfer state, link passwords that worked and game source records are stored on the console under `/data/ps4mount/` or inside the scan folder you use. Logs can include file names, title IDs, local network addresses and error messages; review them before posting them publicly.

## Español

Lodestar no recoge analíticas, telemetría, datos de cuentas ni datos de posesión de juegos, y no envía información a los autores del proyecto.

**Panel en la red local.** El panel web se ejecuta en tu consola (puerto 8770) y solo es accesible desde tu red local. No tiene contraseña: detén Lodestar al terminar si compartes la red con otras personas.

**Descargas que eliges tú.** Si pegas un enlace de descarga o usas la extensión del navegador, la consola contacta directamente con ese servidor para bajar el archivo. El servidor remoto puede ver la dirección IP de la consola como en cualquier descarga HTTP. Lodestar no pasa la transferencia por otro servicio.

**Sin integración de nube.** Lodestar ya no incluye compatibilidad con Google Drive, NAS, SMB, NFS ni FUSE. No pide credenciales de Google ni guarda tokens de nube.

**Archivos locales.** Los ajustes, logs, estado de transferencias, contraseñas de enlaces que funcionaron y registros de origen de juegos se guardan en la consola bajo `/data/ps4mount/` o dentro de la carpeta de escaneo que uses. Los logs pueden incluir nombres de archivos, IDs de juegos, direcciones de la red local y mensajes de error; revísalos antes de publicarlos.
